The adapter did not answer some requests. Its firmware may be older than this page, or it is not in D-Input/Debug mode (hold Start + RB + D-pad Left for 3 s). Profiles, axis settings and button mappings work as usual, but without an answer:
  • Adapter Options, Bluetooth search, Mode Enabled, Rumble Test and the Mouse + Keyboard mapping are not shown;

  • the Touchpad and Motion panel stays empty and Diagnostics has no report;
  • the green highlight follows the button each input is mapped to, not the controller's own button.
If the adapter is in D-Input/Debug mode, update its firmware to the latest version to use them.
